# Endfield SynchroFocus

[English](README_EN.md) | 中文

将《明日方舟：终末地》原本的“短按战技 / 长按终结技”拆分为两个独立的短按键，并支持自定义 1~4 号位的终结技快捷键。

## 下载

前置插件管理器：[Applepie Manager](https://github.com/zonemodAE/ApplepieManager)

您可以在 [Releases](https://github.com/Sasye/EndfieldSynchroFocus/releases) 下载最新发布版或从源代码自行编译。

## 安装

先安装前置插件管理器：[Applepie Manager](https://github.com/zonemodAE/ApplepieManager)，再将以下文件复制到游戏目录（`Endfield.exe` 所在文件夹）：

```
bin/synchro_focus.dll    → 游戏目录/plugin/synchro_focus.dll
```

> 如果您**没有安装过此类型的插件**，您可能需要自行创建 `plugin` 文件夹。

## 配置

在游戏设置的 **Applepie Manager → 插件 → 配置** 中修改功能开关、调试日志及 1~4 号位的终结技快捷键，修改后自动保存。点击当前键名后按下目标键，`Esc` 取消，清除可禁用该快捷键。

新安装和恢复默认时，快捷键依次为 `1/3/4/5`。导入旧配置时保留原有键位，随附旧配置中的键位为 `5/6/7/8`。

- 配置文件：`plugin/config/applepie.synchro_focus.ini`。生成后不再读取旧配置文件；如需手动修改，请先退出游戏，修改后重新启动。
- 日志文件：`plugin/synchro_focus_log.txt`。
